# 獭子哥（Gestalt）

[English](index.md) | 中文

獭子哥（Gestalt）是基于 DeepSeek Harness 构建的开源桌面、Web 与移动 agent（智能体）产品层。它兼容 DSH Profile、插件、CLI 模式和 SDK 入口，并增加可安装客户端、产品工作流和经过审阅的社区集成。
