Android 引导向导

未装 SDK / AVD 时给出命令级指引，逐行可复制

创建第一台 Android 模拟器

需要 Android SDK 命令行工具；插件不会替你下载 SDK 二进制。依次执行以下命令（macOS / Linux）：

✓platform-tools 已安装 2下载系统镜像 3创建 AVD 4启动模拟器
# 下载 Android 系统镜像（API 35，Google APIs ARM64） sdkmanager --install "emulator" "system-images;android-35;google_apis;arm64-v8a"
# 创建名为 Pixel_6_API_35 的 AVD（机型 pixel_6） avdmanager create avd -n Pixel_6_API_35 -k "system-images;android-35;google_apis;arm64-v8a" -d pixel_6
# 启动模拟器（也可以留到会话里让 Agent 启动） emulator -avd Pixel_6_API_35
完成后点右上角「重新检测」，AVD 出现在清单即可打开面板。USB 真机无需此步，打开 USB 调试并授权即可。

iOS 引导向导

runtime 缺失提示 + 模拟器创建 + 真机 WDA 前置说明

iOS 环境差两步

仅 macOS 可用；需要完整 Xcode。先补齐模拟器运行时，再创建一台 iPhone 模拟器。

!

未找到 iOS 模拟器运行时Xcode → Settings → Components 中下载 iOS 平台，或执行以下命令（约数 GB）：

# 下载 iOS 模拟器运行时 xcodebuild -downloadPlatform iOS
# 创建一台 iPhone 16 Pro 模拟器 xcrun simctl create "iPhone 16 Pro" "iPhone 16 Pro" iOS18.4
W

USB 真机的前置条件：WebDriverAgent控制真机需自备 WDA checkout 并完成签名与设备信任；免费开发者证书 7 天过期，过期后需重新构建。就绪后面板内会出现「构建 WDA」入口。

模拟器不需要 WDA；真机上的每次点击都有真实后果，涉及登录与支付的步骤请人工接管。
