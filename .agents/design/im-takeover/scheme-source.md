# DSH IM 账号接管 · 技术方案（proposed · 方向已批准）

> 状态：**方案大方向已获用户批准，插队边界已确认；spec/ticket 已发布，未授权产品实现**。本文件仍是 proposed 方案（非 implemented）；方案 note 已持久化到规格分支的 `.agents/notes/proposed/`，实施 PR 中转写为 present-tense implemented note。
> 认可的产品高保真 UI 与人工评审图解已持久化到 `.agents/design/im-takeover/`；`.design/` 工作台已按用户要求清理，本文不重建。

## Problem

DSH 需要以真实授权账号接管 IM 会话（首期：钉钉经 DWS、旺旺经内部 OpenAPI），让群聊/单聊消息驱动 workspace 内的 Agent，并支持在启用真实托管前用模拟通道验证 workspace 配置。现有能力分散：HiQ 参考项目验证了钉钉链路但代码形态为 bundle 且不再作为复制来源；Travel-Team 验证了旺旺轮询/游标/出站证据但耦合电商业务；DSH 自身的 Session/Agent/工具/审批/Sidebar 接缝正在上游同步中迁移。不能按旧接口直接开工，也不能把通道逻辑塞进 agent-loop。

## Proposal（一句话）

**新增一个 IM 域：少量深模块把“平台差异、游标与可靠投递、路由与触发、模拟双向投递”隐藏在统一接口后，通过 DSH 现有 Session/Agent/工具/审批/Sidebar 接缝装配；真实通道与模拟通道是两个 adapter，被测 Agent 走同一条 IM 输入与发信路径。**

## 范围

- **首期通道**：钉钉（DWS）、旺旺（内部 OpenAPI）。**飞书本期排除**（用户本机不可登录，不预留空驱动、不做 UI 承诺）。

## 模块与接口（深模块，角色划分不定包数量）

### 1. 账号与身份模块
隐藏平台认证流程、凭据 record、连接状态与身份资料完整性。对外：账号列表、平台分步连接流程、连接状态、可用于路由/模拟的身份事实。UI 只见凭据 reference；secret 不出 credentials provider、不进日志/消息/toast。身份资料缺失是独立的不可用原因，不等于断连。

### 2. 路由与触发模块
隐藏账号 + 会话类型（单聊/群聊）+ 全部/指定规则、指定优先、停用保留绑定不回退、账号级总开关、目标 workspace 解析（稳定 workspace 标识而非裸路径）。「全部」是动态匹配：规则保存后新出现的同类会话同样命中，而非绑定时刻的列表快照。群聊触发为三项多选：**被 @、每 N 条新消息、定时（仅存在新消息）**；单聊无该组配置。

本轮方案采用（非逐字用户确认）：任一条件满足即触发（OR）；同批消息同时满足多条件只提交一次；N 统计尚未提交给 Agent 的新消息；定时为固定间隔，不随新消息推迟；提交成功才推进处理进度。

### 3. 消息投递与历史查询模块
隐藏平台分页/游标/冷启动追赶、重复与乱序检查、outbox、回执与失败、历史查询。三分进度分别记录：**已接收**、**已提交 Agent**、**对外已发送**——避免重启后重复提交或漏消息。查询范围限当前会话/当前模拟实例；导入 JSONL 仅作可查询背景，不逐条触发。发送结果不明且无法安全去重时标记「结果待确认」，不盲目重发。

### 4. DSH 执行协调模块
隐藏创建/恢复执行 Session、把消息变成模型可见输入、派发长任务、停止。入站消息携带正式来源数据（通道、发送者身份、触发原因），不塞正文伪装。**外部 IM 发言不是 workspace owner 指令**，来源必须使权限层可区分。长任务用 continuable child；是否挂 Goal 由任务语义决定。

**新触发直接插队**（用户已确认，含精确边界）：以现有 steer/优先 inbox 为候选机制，在**最近安全的 step boundary 以高优先生效；不强制中断模型生成，不动已开始的工具执行**。用户两次明确此边界，方案即按此设计。

### 5. 模拟 transport 与工具门控模块
模拟用户 Agent 所在 workspace 配置测试目标后，该 workspace 的 Agent 才获得模拟工具（创建/按身份发送/结束）；被测 workspace 不因成为目标获得这些工具；工具不越过已配置目标。一个模拟用户 Session 对应一个实例；多个独立 Session 可并发测试同一目标。实例固定创建时的目标与身份名单；配置变更/清除仅影响新建实例，旧实例保留收发与停止能力。模拟不要求真实账号连通，但要求目标已配置且身份资料完整。

### 6. UI 集成模块
按已认可 UI 装配：全局设置认证、工作区导航设置（IM 接管 / IM 模拟）、Sidebar 双边 IM 对话。其余 chrome 保持正式产品表现。

## 关键数据与时序

### 数据关系（概念级，不定 schema）
`ImAccount`（平台/身份/凭据 reference/状态）→ `ImRouteRule`（账号/类型/全部或指定/workspace/启用/群触发）→ `ImConversationTarget`（实际会话/身份资料快照/归属规则）；`InboundMessage`（来源分类证据/平台 id/cursor/raw reference）；`OutboundMessage`（requestId/意图 AI 或人工/状态/回执）；`SimulationInstance`（创建时目标/双端 Session/成员名单/历史引用/停止状态）。

### 真实通道时序
```text
平台消息 → 记录原始证据 → 去重/顺序校验 → 推进接收游标
        → 来源分类（外部 / AI 回显 / 本人原生 / 本人 DSH / 待确认）
        → 路由 + 触发判定 → 作为正式来源输入提交 Agent（插队）
Agent 发信 → 权限检查 → outbox → adapter 发送 → 记录回执
回显命中出站证据 → 不再触发；不可信匹配 → 保留“不确定”
```

### 模拟通道时序
```text
模拟用户 Agent（已配置目标的 workspace）→ 创建实例（固定目标/成员/可选 JSONL）
→ 模拟发送（群聊可指定成员、可注入本人发言）→ 系统投递给被测 Agent（格式与真实一致）
被测 Agent 走同一条 IM 发信路径 → 模拟 adapter 投递回原实例
停止 → 关闭本实例双向投递并请求停止实例专属执行；不影响其他实例与真实会话
```

## 生命周期、取消与恢复

- **重启**：完全沿用当前应用普通 Session 的默认行为（普通 Session 续跑则续跑、停则停），IM 与模拟不做定制恢复。
- **显式停止**：模拟实例显式停止后不可复活；真实会话停用后不再由新消息触发、待发 AI 消息不再发送，已在运行的后台任务不自动取消、结果留在 DSH；恢复启用时不批量补发旧队列。
- **账号级暂停**：暂停该账号的自动处理但不改写各路由开关，不阻止本人从 DSH 手动发送，也不影响模拟通道与运行中的模拟实例。
- **改绑**：真实会话改绑在会话切换点生效，运行中任务保留原 workspace 归属；模拟实例永远固定创建时目标。
- **配置变更**：workspace 模拟配置变更仅影响新建实例；已确认语义。

## 权限与安全

- IM 外部消息不产生授权；群成员或买家的「同意」不批准任何操作。审批只在 DSH 页面（复用原生 approval seam），IM 不发审批通知。
- 凭据仅在 credentials provider 内；日志、消息、UI 只见 reference。
- 模拟通道的投递隔离是程序强制（实例上下文选择 adapter），不是提示词约束；模拟绝不真实外发，模拟只替换 IM 投递、不接管其他工具的副作用。
- 平台无法证明的身份与回执保留 unknown；不按昵称或正文自称推断。

## 平台事实（证据与边界）

- **钉钉 DWS（1.0.52.1）**：本机 auth 有效；公开 `event consume` / `chat message list` / `send` / `reply` / `query-send-status` 存在。**dry-run 与 mock 证据不能声称真实收发已测试**；登录交互形态、本人消息证据与回执语义待实测。
- **旺旺**：接入字段 endpoint/AccessKey/SecretKey；merchantId 来自商家目录/准入，**无 whoami 接口**——不承诺自动发现商家身份，绑定验证路径待平台侧确认。游标追赶、出站证据、发送者授权机制参考 Travel-Team 已验证实现。
- **飞书**：本期排除。
- **HiQ**：仅参考实现与对照问题；不复制代码/UI 文案，许可不再是阻塞项（用户已拍板）。

## 可观察验证（验收形态，不定 fixture）

1. **恢复**：崩溃/重启后已接收未提交的消息补提交一次且仅一次；已提交不重复。
2. **去重**：同批消息满足多个触发条件只提交一次；AI 出站回显不再触发新一轮。
3. **出站未知**：结果不明时显示「待确认」且不自动重发；确认失败可人工重试。
4. **模拟不外发**：模拟实例的每条出站消息只回到实例；构造跨实例/真实目标消息应被拒绝。
5. **插队**：新触发在 Agent 忙时于最近合法 step boundary 生效；不取消进行中的工具调用。
6. **工具门控**：未配置模拟目标的 workspace 无模拟工具；被测 workspace 不因成为目标获得模拟工具。
7. **快照**：真实装配跑通关键路径（真实 IM 面板、模拟双边、工作区设置两节、认证流程）的 keyless snapshot。

## Alternatives considered

- **按 HiQ 拓扑整包复制（Resident+Leaf+outbox）**：放弃。HiQ 与 DWS alias 不同、bundle 形态不可拆改、钉钉专属结构需重写；只保留机制参照。
- **移植 Travel-Team channel-worker 整体**：放弃。其业务授权、HTTP 层、存储布局与电商逻辑耦合；只吸纳轮询/游标/出站证据语义。
- **修改 agent-loop 支持 IM 唤醒**：放弃。违反“插件不改 loop”约束；唤醒用现有 steer/inbox 接缝。
- **模拟做成独立测试工具链（测试专用发信工具）**：放弃。会破坏真实/模拟同路径这一核心价值；改为同 Consumer 按实例上下文选 adapter。
- **为 IM 定制重启/中断恢复**：放弃（用户批示）。遵循普通 Session 默认。
- **人工发言自动冻结 AI**：放弃（用户批示）。人工消息标记来源，由 workspace 策略决定行为。

## Risks / 待核验

1. 固定 SHA `96d3358112…` 的源码接口复核未完成：Session 事件扩展、steer/inbox、tools eligibility、subagent、settings/workspace/Sidebar 装配均待读该 SHA 源码确认；本方案接口为概念级。
2. DWS 真实收发、本人消息证据、回执语义未实测（仅 dry-run/mock 级证据）。
3. 旺旺商家身份绑定验证路径未知（无 whoami）。
4. 群触发组合语义（OR/去重/计数窗口/周期边界）为本轮方案采用，未获逐字确认。
5. 同步分支后续变化由单一集成者合入时，高重叠区（session/tools/subagent/sidebar/workspace UI）可能产生语义返工。
