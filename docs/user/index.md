# Gestalt

English | [中文](index.zh.md)

Gestalt is the open-source product layer built on DeepSeek Harness for desktop, Web, and mobile agent work. It preserves DSH profiles, plugins, CLI modes, and SDK entry points while adding installable clients, product workflows, and reviewed community integrations.
