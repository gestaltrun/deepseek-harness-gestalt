# Agent Note: 通过 workspace Agent 接管 IM 账号

Status: proposed

[English](2026-09-07-im-account-takeover.md) | 中文

## Problem

DeepSeek Harness 需要用真实授权账号接收 IM 消息，把消息路由到由提示词、技能和权限支配接收 Agent 的 workspace，并让负责人在启用真实托管前检查与验证该配置。这项工作横跨持久路由、平台传输、可回放的 Agent 输入、工具授权和 GUI 呈现。现有参考只证明了部分行为，没有提供可交付边界：钉钉参考项目验证了 DWS 工作流，但只作为机制参考；旺旺参考证明了游标推进和出站证据，却耦合商家业务逻辑；这些参考必须接入的 DSH 接缝仍在上游同步分支中迁移。

## Proposal

新增 IM 域，用小接口隐藏平台差异、路由、游标进度、可靠出站投递和模拟投递。真实通道与模拟通道是同一消息输入和发信工具路径后的两个 adapter。首期平台为经 DWS 的钉钉和经已核验内部 OpenAPI 的旺旺。飞书不在本期范围：不预留空驱动、不做设置流程、不做 UI 承诺。

实施计划以固定同步快照 `96d33581128676a469a1587ea85e0339e4853cf0` 为基线；规格审阅从 `master` 的 `5e55fbc0f9e699fa005028d2a591517fc72ba09e` 开始。该快照的源码接口尚未在安全可读的 checkout 中复核，因此本提案只命名概念角色，并把该复核记录为第一个 blocker，而不是把安装版本 API 当作已验证事实。

完整方案源稿与评审图解位于[持久设计归档](../../../design/im-takeover/README.zh.md)。已认可的高保真原型和精选纯示例截图归档在同一目录，不包含私人 GUI 参考截图。

### 范围与权限

- 账号连接在现有 Settings 中配置；每个平台保留自己的流程。凭据留在 credential seam 之后，不进入会话日志、普通配置记录、截图或通知。
- 路由在 workspace 设置中配置。规则选择账号、单聊或群聊、全部或指定目标。「全部」规则动态覆盖保存后新出现的同类会话。指定规则优先于全部规则；停用指定规则保留绑定而不回退；绑定不等于启用。
- 群聊触发为多选：被 @、每 N 条新消息、固定间隔且存在新消息。方案采用任一条件满足、重叠批次只提交一次、从未提交给 Agent 的消息开始计数、新消息不推迟固定间隔、提交成功才推进进度。
- 新触发在最近安全 step boundary 优先生效。它不强制中断模型生成，也不取消已经开始的工具执行。
- 原生 IM 客户端或 DSH 中的人工消息明确区分。外部 IM 文本从不授权操作，审批只留在 DSH 原生审批界面。
- 模拟用户 Agent 所在 workspace 选择已配置接管目标后才获得模拟工具。一个模拟用户 Session 拥有一个模拟实例；独立的模拟用户 Session 可并发。实例保留创建时选择的目标，即使 workspace 配置随后变化；显式停止的实例不能复活。
- 重启行为沿用普通 Session 默认策略。IM 域不增加定制的中断恢复，也不强制已停止的模拟继续。停用真实接待后不再发送待发 AI 消息、恢复时不批量补发；账号级暂停不影响 DSH 手动发送与模拟实例。

### 模块角色

- **账号与身份模块**：拥有平台特定连接流程、凭据引用、连接状态和身份证据完整性。
- **路由与触发模块**：拥有规则解析、账号级暂停、workspace 目标解析和群聊触发进度。
- **消息投递模块**：拥有入站顺序与去重、已接收/已提交/已发送的进度拆分、历史查询、出站证据、回执和结果未知处理。
- **执行协调模块**：把已接纳消息转换为目标 workspace 中可重建的模型可见输入，并通过现有 subagent 能力委托长任务，不修改 agent loop。
- **模拟传输与工具模块**：拥有本地双向投递、固定实例身份、成员选择、JSONL 背景历史和实例停止语义。模拟只替换 IM 投递；其他工具保留自身行为。
- **UI Consumer**：按已认可原型装配账号设置、workspace 设置和 Better Sidebar 会话视图。

### 平台证据

钉钉证据来自本机安装的 DWS CLI 和 HiQ 参考实现的行为，不来自复制其代码。已安装 CLI 暴露用户认证状态、用户/群事件 schema、消息历史、发送、引用回复、发送状态查询和 dry-run 订阅命令。HiQ 使用旧的内部命令别名，因此 adapter 约定必须面向当前安装的公开命令。

旺旺证据来自 Travel-Team 实现：endpoint/access-key/secret-key 配置、事件拉取与游标推进、来源与发送者校验、producer 身份、出站回执和历史列表。其 OpenAPI 约定没有 whoami 操作，因此商家身份来自已配置身份资料，而不是凭据校验后的发现。

## Alternatives considered

**等同步分支先合入 `master`。** 拒绝，因为用户选择同步快照作为方案基线。本提案冻结确切提交，并把接口复核作为第一个 blocker，而不是跟踪移动的 upstream HEAD。

**以 HiQ 参考项目作为实现基础并复制。** 拒绝，因为其当前命令别名与本机 DWS CLI 不同，源码是 bundle JavaScript 而非可维护的包结构，且用户已把它收窄为机制参考与问题对照。

**在真实 IM 工具旁新增模拟专用回复路径。** 拒绝，因为这会让配置通过模拟却在真实路径失败。被测 Agent 使用同一输入与发信工具路径；实例上下文选择模拟 adapter。

**为 IM 新增独立审批或中断通道。** 拒绝，因为 DSH 原生审批拥有授权，且用户选择了最近安全 step 插队，而不是强制取消。

## Acceptance criteria

- 固定快照被发布或 materialize 供复核，第一个 blocker 记录仍未检查的准确源码接口。
- 规格分支携带本 proposed note、规格、票据依赖图、体验路线和清理后的持久设计归档。
- tracker 包含一个规格和 blocker 优先的票据；每票都有可观察验收和聚焦的 keyless 证据要求。
- 真实外发、真实模型调用和真实账号读取不属于票据证据，除非另行授权。
- 固定接口 blocker 解决前，不从本提案启动实现 writer。

## Risks

- 规格 PR 的审阅分支派生自 `origin/master`，不包含固定快照；快照当前可经已推送旧 head `c2914ed9a5b3a8d51b2c0800d383376705e0da81` 的祖先链或本地保留 ref `codex/im-takeover-preserved-6d911d` 获取。lease 更新后 c291 已失去分支引用，GitHub 不保证永久保留未引用提交，因此正式实施前须由同步项目方正式发布固定基线；这是实施前置条件，不阻塞当前规格交付。实施剩余 blocker 是对固定快照做源码接口与检查复核。
- 安装版本的 Session、Agent、tools、subagent、settings、workspace 和 Sidebar API 不能证明与固定快照兼容。
- DWS 真实发送、发送者证据和回执语义只有 dry-run 与 schema 证据，没有已授权的真实消息测试。
- 旺旺已核验 OpenAPI 没有 whoami，因此不能用凭据证明商家身份。
- 已认可 UI 归档保留历史飞书和触发评审内容；归档 README 记录后续范围覆盖，但实施必须遵循本提案而不是旧原型文案。
