桌面与手机

在电脑上开始，在手机上继续

DeepSeek Gestalt 是这条 Harness 的产品形态：桌面端负责完整会话，手机配对后共用同一条会话。

DESKTOP

桌面端

在自己的电脑上安装 DeepSeek Gestalt，打开完整会话：写代码、用工具、回放轨迹。需要时从本仓库的发布页下载。

PHONE

手机端

把手机和桌面配对后，可以在手机上继续同一条会话：看进度、补一句、接着干，不必另开一条线。

Agent = Model + Harness

Harness 让 Agent 在真实场景中持续工作

模型是 Agent 的灵魂。Gestalt 把现成的 Harness 做成可安装桌面产品，并用自有 Platform 接上手机。

Cordis 内核

CORDIS KERNEL

Cordis 内核只负责插件的加载、卸载和依赖关系，不承载 Agent 的具体能力。

插件提供能力

CAPABILITIES AS PLUGINS

模型、工具、技能、会话、沙箱、存储、循环、调度、UI 等所有 Agent 能力均由插件提供，并通过 Cordis 服务与事件彼此协作。

配置层自由组合

COMPOSE IN CONFIGURATION

开发者无需改动源码，即可在配置层选择、替换或扩展任一能力。

桌面、网页，同一套模式

标准模式

完整编码 Agent：文件编辑、Shell、检索、Skills、计划、目标、子代理与工作流。

PTC 模式

标准能力加上 Code Mode SDK，模型用一段 TypeScript 组合多步工具。

极简模式

只留持久 bash 与 str_replace_editor，给最小环境做模型基准。

创造模式

检查运行时、试验 Cordis 插件，并据此组合新的 Agent preset。
